## Before recording and submitting

1. Verify the intended Git commit is deployed, or use the local setup instructions with a sandbox business account and a separate sandbox buyer account.
2. Complete one buyer-approved capture from the browser. Keep the order and capture IDs visible in the product, with account details and credentials cropped out.
3. Show the workflow in order. Review a payment request with actual provider telemetry, approve the allowed request in PayPal sandbox, and show the confirmed capture in the workspace. Use a blocked request or the AG Grid audit trail as supporting evidence.
4. Record the finished flow in under three minutes. Use your own narration and material you have rights to use. Upload the video publicly to YouTube and paste the link into Devpost.
5. Paste the project copy and functional demo link into Devpost. Provide sandbox access instructions through the appropriate private fields if needed. Keep the demo available through judging.

Recording and public upload are pending. Use only the actual provider workflow in the video. Omit experimental benchmark claims and unverified integrations.
